# 🎬 Netflix Data Analysis

This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python.

## 📊 Project Overview

The goal of this project is to explore Netflix movies and TV shows and understand different patterns in the dataset through data analysis and visualization.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- KaggleHub

## 📁 Dataset

The dataset contains information about Netflix movies and TV shows, including:

- Title
- Type
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Date Added

## 📈 Analysis Performed

Some of the visualizations and analysis include:

- Movies vs TV Shows
- Movies and TV Shows released over the years
- Distribution of ratings
- Content by country
- Most common genres
- Content duration analysis

## 📊 Visualizations

The project uses Matplotlib to create different charts such as:

- Bar Charts
- Line Charts
- Pie Charts
